# Установка CARLA на Windows и сбор мультикамерного датасета

Пошаговая инструкция: установка готовой сборки **CARLA 0.9.16** (на Unreal Engine 4) без установки Unreal Engine, настройка Python и запуск сбора кадров одного перекрёстка с N камер.

> **Почему 0.9.16, а не 0.10.x?** Ветка 0.10.x работает на Unreal Engine 5: она тяжелее, требует мощнее видеокарту и в ней меньше карт. 0.9.16 — последняя версия на UE4, стабильная и с полным набором карт. Сам Unreal Engine устанавливать **не нужно**: скачивается уже собранный симулятор, его достаточно распаковать и запустить.

---

```
carla_multicam_kit/

├── run_capture_config.bat      ← сбор с камерами из JSON-конфига
```

## 1. Требования к компьютеру

| | Минимум | Рекомендуется |
|---|---|---|
| ОС | Windows 10 64-bit | Windows 11 |
| Видеокарта | NVIDIA с 6 ГБ памяти (GTX 1660 / RTX 2060) | RTX 3070 и выше, 8+ ГБ |
| ОЗУ | 16 ГБ | 32 ГБ |
| Диск | 30 ГБ свободно (лучше SSD) | 60 ГБ, если с доп. картами |
| Python | 3.10, 3.11 или 3.12 (64-bit) | 3.12 |

Интегрированная графика Intel и видеокарты AMD формально могут запуститься, но часто дают сбои. Для стабильной работы нужна NVIDIA.

---

## 2. Подготовка системы (один раз)

### 2.1. Драйвер видеокарты
Обнови драйвер NVIDIA до последней версии: https://www.nvidia.com/drivers (или через приложение NVIDIA). Перезагрузи компьютер.

### 2.2. DirectX и Visual C++
CARLA использует компоненты DirectX и Visual C++. Если их нет, при запуске будет ошибка про `xinput1_3.dll`, `d3dx...dll` или `VCRUNTIME140.dll`.

1. **DirectX End-User Runtime**: https://www.microsoft.com/en-us/download/details.aspx?id=35 → скачать и установить.
2. **Visual C++ Redistributable 2015–2022 (x64)**: https://aka.ms/vs/17/release/vc_redist.x64.exe → установить.

### 2.3. Python
1. Скачай Python 3.12 (Windows installer 64-bit): https://www.python.org/downloads/windows/
2. При установке **обязательно** отметь галочки:
   - ☑ `Add python.exe to PATH`
   - ☑ `Use admin privileges when installing py.exe` / `py launcher`
3. Проверь в командной строке (`Win+R` → `cmd`):
   ```bat
   py -3.12 --version
   ```
   Должно вывести `Python 3.12.x`.

> Если у тебя уже стоит Python 3.10 или 3.11, можно использовать его: поменяй `PY_VERSION` в `config.bat`. Python 3.13+ и 3.9- для CARLA 0.9.16 на Windows **не подойдут** (для них нет готового пакета `carla`).

### 2.4. (Необязательно) 7-Zip
Архив CARLA большой. Скрипт распакует его и встроенными средствами Windows, но с 7-Zip (https://www.7-zip.org/) это быстрее и надёжнее.

## 3. Распаковка этого архива

Распакуй `carla_multicam_kit.zip` в папку **без пробелов и русских букв** в пути, например:

```
C:\carla_multicam_kit\
```

❌ Плохо: `C:\Users\Иван\Рабочий стол\carla kit\`
✅ Хорошо: `C:\carla_multicam_kit\`, `D:\work\carla_multicam_kit\`

Открой `config.bat` в Блокноте и при необходимости поменяй:

```bat
set CARLA_VERSION=0.9.16
set CARLA_ROOT=C:\CARLA\CARLA_%CARLA_VERSION%   ← куда ставить CARLA
set PY_VERSION=3.12                              ← версия Python
```

---

## 4. Установка CARLA

### Вариант А — автоматически (рекомендуется)
Запусти двойным кликом:

```
scripts\01_download_carla.bat
```

Скрипт:
1. Скачает `CARLA_0.9.16.zip` (несколько ГБ) с официального сервера `downloads.carlasim.com`. Если загрузка оборвётся, запусти скрипт снова: он продолжит с места обрыва.
2. Распакует его в `C:\CARLA\CARLA_0.9.16\`.
3. По желанию (ответ `y` на вопрос) скачает и распакует **дополнительные карты** (Town06, Town07 и др.). Для старта они не нужны: в основном пакете уже есть Town01–Town05 и Town10HD.

### Вариант Б — вручную
1. Открой страницу релизов: https://github.com/carla-simulator/carla/releases/tag/0.9.16
2. Скачай `[Windows] CARLA_0.9.16.zip` (прямая ссылка: https://downloads.carlasim.com/Windows/CARLA_0.9.16.zip).
3. Распакуй в `C:\CARLA\CARLA_0.9.16\` так, чтобы файл лежал по пути `C:\CARLA\CARLA_0.9.16\CarlaUE4.exe`.
4. (Необязательно) Скачай `AdditionalMaps_0.9.16.zip` и распакуй **в ту же папку** с заменой файлов.

### Проверка
В папке `C:\CARLA\CARLA_0.9.16\` должны быть:
```
CarlaUE4.exe
CarlaUE4\
Engine\
PythonAPI\
```

## 5. Установка Python-окружения

Запусти:

```
scripts\02_setup_python.bat
```

Скрипт:
1. Создаст виртуальное окружение `.venv` внутри папки проекта (системный Python не засоряется).
2. Поставит `numpy` и `pillow`.
3. Поставит клиент `carla==0.9.16` с PyPI. Если не получится, возьмёт wheel из `C:\CARLA\CARLA_0.9.16\PythonAPI\carla\dist\`.
4. Проверит, что всё импортируется.

В конце должно быть `carla OK: ...` и `Готово`.

> ⚠️ **Версия клиента `carla` должна совпадать с версией сервера.** Если сменишь версию CARLA, удали папку `.venv` и запусти шаг 5 заново.

---

## 6. Первый запуск сервера

```
scripts\03_start_carla.bat
```

Откроется окно CARLA с городом. **Первый запуск долгий** (1–3 минуты, а иногда и дольше): компилируются шейдеры. Можно полетать камерой: `WASD` + мышь (правая кнопка зажата).

Варианты запуска:

```bat
scripts\03_start_carla.bat                 :: Epic качество, с окном
scripts\03_start_carla.bat Low             :: Low — для слабой видеокарты
scripts\03_start_carla.bat Epic offscreen  :: без окна (рендер идёт, но окно не показывается)
```

> Брандмауэр Windows может спросить разрешение для `CarlaUE4.exe`. Разреши для **частных сетей**: клиент подключается к серверу через `localhost:2000`.

## 7. Проверка связи

Пока окно CARLA открыто, запусти:

## 8. Сбор датасета

### 8.1. Простой запуск
Открой `run_capture.bat` в Блокноте и задай параметры в начале файла:

```bat
REM Количество камер (ракурсов)
set CAMERAS=3
REM Снимок раз в 10 секунд симуляции
set INTERVAL=10
REM Сколько снимков
set SNAPSHOTS=50
set TOWN=Town10HD_Opt
REM Номер перекрёстка
set JUNCTION=0
REM Высота камер и расстояние до центра, м
set CAM_HEIGHT=8
set RADIUS=25
REM clean / cctv / hd
set PRESET=cctv
set SENSORS=rgb,semantic
set WEATHER=ClearNoon
```

> Не пиши комментарии в той же строке, что и `set`: в .bat они станут частью значения.

Сохрани и запусти `run_capture.bat` (сервер из шага 6 должен работать).

Любые дополнительные параметры `carla_multicam.py` можно дописать в командной строке, они добавятся в конец:

```bat
run_capture.bat --pitch -35 --fov 70 --grayscale
```

### 8.2. Каждая камера отдельно (JSON)
Скопируй `configs\cameras_example.json`, поправь под себя и **перетащи свой .json на `run_capture_config.bat`** (или запусти без аргументов, тогда возьмётся пример).

Поля камеры в JSON:

| Поле | Что значит |
|---|---|
| `name` | имя камеры (будет в именах файлов) |
| `angle` + `radius` | позиция на круге вокруг перекрёстка (градусы, метры) |
| `x`, `y` | позиция в метрах относительно центра перекрёстка (вместо angle/radius) |
| `height` | высота, м |
| `pitch` | наклон вниз, градусы (например −35); без него камера сама наводится на центр |
| `yaw` / `yaw_offset` | точный поворот / доворот от направления на центр |
| `roll` | крен |
| `aim_height` | высота точки прицеливания над центром, м |
| `fov` | угол обзора, градусы |
| `width`, `height_px` | разрешение кадра |

### 8.3. Пакетный сбор (на ночь)
`run_batch.bat` перебирает несколько перекрёстков и погод, складывая каждую комбинацию в свою папку. Списки задаются в начале файла:

```bat
set JUNCTIONS=0 1 2 3
set WEATHERS=ClearNoon CloudyNoon WetNoon HardRainNoon ClearSunset ClearNight
```

### 8.4. Все параметры скрипта
```bat
.venv\Scripts\python.exe carla_multicam.py --help
```

## 9. Что получается на выходе

```
output\run_20261015_183000\
├── cameras.json             ← позиции, углы, FOV и матрицы камер
├── snap_000001\
│   ├── cam_01_rgb.jpg
│   ├── cam_01_semantic.png
│   ├── cam_02_rgb.jpg
│   ├── ...
│   └── meta.json            ← время симуляции + координаты и габариты всех машин и пешеходов
├── snap_000002\
└── ...
```

Все файлы в одной папке `snap_XXXXXX` сняты **в один и тот же момент симуляции**.

Сырые маски:
- `semantic`: номер класса в красном канале (палитра CityScapes: 14 — машина, 12 — пешеход и т.д.).
- `instance`: класс в R, уникальный ID объекта в каналах G+B (один и тот же объект имеет один ID на всех камерах).
- `depth`: глубина закодирована в RGB. Метры = `(R + G·256 + B·256²) / (256³ − 1) · 1000`.

Флаг `--colorize` сохраняет маски в цветном виде, чтобы их было удобно смотреть глазами.

## 10. Частые проблемы

| Симптом | Решение |
|---|---|
| `CarlaUE4.exe` сразу закрывается / ошибка про DLL | Поставь DirectX и VC++ из п. 2.2, обнови драйвер |
| Окно чёрное, очень низкий FPS | Запусти с `Low`: `scripts\03_start_carla.bat Low` |
| `time-out of 10000ms while waiting for the simulator` | Сервер ещё грузится. Подожди и повтори, или увеличь ожидание |
| `ModuleNotFoundError: No module named 'carla'` | Запусти `scripts\02_setup_python.bat` заново |
| Ошибки при `import carla` / несовпадение версий | Версии клиента и сервера разные. Удали `.venv`, проверь `CARLA_VERSION` и повтори шаг 5 |
| `Пропущен кадр ...` / зависание | Слишком много камер или высокое разрешение для твоей видеокарты. Уменьши `CAMERAS`, разрешение (`--preset cctv`) или число типов сенсоров |
| Карта не найдена (`--town Town06`) | Это доп. карта, её нужно скачать (п. 4, ответ `y`) |
| Ошибка при распаковке, кракозябры в пути | Путь содержит пробелы или кириллицу. Перенеси папки (п. 3) |
| После прерывания (Ctrl+C) CARLA «зависла» | Скрипт возвращает асинхронный режим в `finally`. Если не помогло, перезапусти сервер |
| Мало трафика на перекрёстке | Увеличь `VEHICLES`, попробуй другой `JUNCTION` |

### Нагрузка, чтобы сориентироваться
Каждая камера × каждый тип сенсора рендерится на каждом шаге симуляции. Например, 4 камеры × `rgb,semantic` = 8 рендеров на шаг. Если на шаге 0.05 с (20 FPS) работает медленно, скрипт всё равно отработает корректно, просто дольше: интервал считается в секундах **симуляции**, а не реального времени.
